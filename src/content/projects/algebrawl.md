You battle Gauss, Newton and Fibonacci, and every attack is a problem you have to solve. KaTeX renders the math, and the Web Audio API makes the sound effects on the fly.

It started as a Java Swing project for a college class. I later ported it to the web so anyone can play it in a browser without installing anything. The original Java version is still in the repo.
