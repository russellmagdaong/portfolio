# Rebrand (one place, drawn from the street) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the stock "retro landing page" web layer (text version, chooser, HUD, 404) with one system derived from the game's own art, add a sign-style pixel font, and redraw the school's exterior.

**Architecture:** Shared brand tokens (sign colour per place, the dark ground and card, text colours, title font) live in `src/styles/global.css` and are read by `text.css`, `landing.css` and `game.css`. The text version is rebuilt as one postcard: `PostcardFront.astro` (the game's real street from `hubConfig()`), `PostcardBack.astro` (the letter), and `Chapter.astro` (one per place), keeping every `data-place` / `data-spot` hook so `src/game/textsite.ts` and `src/game/spot.ts` keep syncing with the game. The font is drawn in Aseprite and compiled to WOFF2 by a Node script.

**Tech Stack:** Astro 7, Tailwind 4, plain CSS, TypeScript; Aseprite Lua (batch); Node 22 `node:test` + headless Edge over CDP for checks; `opentype.js` + `wawoff2` (new dev dependencies) for the font.

**Spec:** `docs/superpowers/specs/2026-11-17-rebrand-design.md` (approved 2026-11-17). Also read `PRODUCT.md` and `.impeccable/surfaces/src-components-text-textsite-astro.md` (the text page's direction contract).

## Global Constraints

- **No commits and no git commands that change anything** (`art/HANDOFF.md`; Russell commits himself). Each task ends at a checkpoint instead.
- No scroll snapping, pinned sections or hijacked scrolling. The page never scrolls sideways; only the street front may scroll sideways inside its own frame.
- Art uses only colours from `art/palette.gpl`. Aseprite is `C:\aseprite\build\bin\aseprite.exe` (batch: `-b --script <file>`). Never re-run an existing draw script on an existing file (`hub.lua`, `lettering.lua`, scene scripts); only the new `font.lua` and `school.lua` run.
- Every existing `data-place`, `data-spot`, `data-goto`, `data-play`, `data-change-ui`, `data-cert-open` hook keeps its value, except the `testimonials` spot, which is removed with its card.
- Sign colours: home `#46e6e1`, school `#be6eff`, arcade `#ff4f9a`, store `#7cf05a`, trophy-shop `#ffe24d`, post-office `#ff463c`. On the dark theme they are also the coloured-text colours (no separate inks).
- **Dark theme:** ground `#0d0b1a`, card `#171433`, rule `#35354c`, body text `#b3b6c9`, headings `#ffffff`, soft text `#8c8fa8`. Body text in IBM Plex Sans, about 17px, measure 60 to 75 characters. No glows, blurs or text shadows.
- Title font sizes are 16, 24, 32, 48 or 64 px only. Jersey 10 for labels. No Press Start 2P or IBM Plex Mono on the text page or chooser.
- Hard offset shadows only on buttons. Sign colours are for labels, markers, rules and stamps, never running body text.
- Headings never end in a full stop. Factual copy is unchanged except where the spec says.
- `prefers-reduced-motion: reduce` stops every animation on the text page and chooser.
- Checks run against the dev server Russell already has on `http://localhost:4321` (override with `CHECK_BASE`). Screenshots go to `.impeccable/review/`.

### Task 2: Font pipeline (glyphs → WOFF2)

**Files:**
- Create: `scripts/art/font/chars.txt`, `scripts/art/font/dump.lua`, `scripts/art/font/build.mjs`, `scripts/check/font.test.mjs`
- Modify: `package.json` (devDependencies `opentype.js`, `wawoff2`; script `"font": "node scripts/art/font/build.mjs"`)

**Interfaces:**
- `chars.txt`: one line, the characters in cell order: `ABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789.,'’:;-–!?&/·()"`. The space is implicit and needs no cell.
- The cell grid in `art/font.aseprite` is 16 columns, each cell 8 px wide and 9 px tall. A glyph's pixels sit at the cell's top-left. Rows 0 to 6 are cap height, the baseline is under row 6, and row 7 is the one row of descent. Any opaque pixel is ink.
- `dump.lua` reads `art/font.aseprite` frame 1 and `chars.txt`. It writes JSON `{ "<char>": ["0110", ...8 row strings] }` to the path in env `FONT_JSON`.
- `build.mjs` exports `glyphsToFont(glyphs: Record<string, string[]>): ArrayBuffer` (OTF via opentype.js) and `toWoff2(otf: ArrayBuffer): Promise<Uint8Array>`. Run as the CLI, it runs Aseprite with `dump.lua` into a temp file, then writes `src/assets/fonts/russm-sign.woff2`.
- Metrics: 1 art px = 128 units, `unitsPerEm` 1024, ascender 896, descender -128. Advance = (rightmost inked column + 1) × 128 + 128 (a 1 px gap); the space advance is 512. Family name `Russm Sign`.
- Each uppercase glyph also maps its lowercase code point (`unicodes: [65, 97]` and so on), so lowercase text renders in caps.
- Contours: one rectangle per horizontal run of ink pixels in a row.

- [ ] **Step 1: Write `font.test.mjs` (unit).** Use the fixture `{ A: ['01110','10001','10001','11111','10001','10001','10001','00000'] }`. `glyphsToFont` → `opentype.parse` gives `unitsPerEm === 1024`. `charToGlyph('A').advanceWidth === 768`. `charToGlyph('a').index === charToGlyph('A').index`. `charToGlyph(' ').advanceWidth === 512`. The 'A' path has commands. The bytes from `toWoff2` start with `wOF2`. `test('shipped font covers chars.txt')` is skipped when `src/assets/fonts/russm-sign.woff2` doesn't exist. Otherwise it decompresses the file (`wawoff2.decompress`) and parses it, and asserts every character in `chars.txt` maps to a glyph other than `.notdef`.
- [ ] **Step 2: Run `npm run check`.** Expected: the font unit tests FAIL (module missing).
